# 할일이많아 · Google Play 출시 안내

이 폴더에 Play Console에 올릴 자료가 모두 들어 있습니다. 계정 가입·결제·본인 인증과 Console 입력은 직접 하셔야 하고, 나머지는 여기 있는 파일과 문구를 그대로 쓰면 됩니다.

| 업로드 파일(AAB) | [최신 Release](https://github.com/JunRepos/serial-todo/releases/latest)의 `serial-todo.aab` | push할 때마다 자동 빌드 |

## 1. 개발자 계정 만들기 (직접)

1. https://play.google.com/console/signup 에서 **개인** 계정으로 가입합니다.
2. 등록비 25달러(1회)를 결제하고, 신분증으로 본인 인증, 휴대전화 인증을 마칩니다. 인증에 며칠 걸릴 수 있습니다.
3. 개발자 이름(스토어에 공개됨)과 연락처 이메일을 정합니다.

## 2. 앱 만들기

Play Console → **앱 만들기**

- 앱 이름: `할일이많아`
- 기본 언어: 한국어
- 앱 또는 게임: 앱 / 유료 또는 무료: 무료
- 선언 항목 체크

## 3. 스토어 등록정보 (기본 스토어 등록정보)

**앱 이름** (30자 이내)

할일이많아

**간단한 설명** (80자 이내)
```
큰 목표를 쪼개고 순서대로. 선행 관계로 실행 순서를 계산하는 할 일 앱
```

**자세한 설명**
```
할 일이 너무 많아 어디서부터 해야 할지 막막할 때.
할일이많아는 큰 목표를 작게 쪼개고, 무엇부터 할지 순서를 계산해 줍니다.

■ 목표 → 프로젝트 → 액션
큰 목표를 프로젝트로, 프로젝트를 오늘 바로 할 수 있는 액션으로 나눕니다.
여러 줄을 붙여넣으면 들여쓰기대로 한 번에 만들어져요.

■ 순서는 앱이 계산
"이게 끝나야 시작"할 일을 정하거나 하위 항목을 순차 진행으로 두면,
실행 단계를 자동으로 정리하고 지금 할 수 있는 일과 기다려야 하는 일을 나눠 보여 줍니다.

■ 오늘 할 일에 집중
★로 오늘 할 일을 고르고, 오른쪽으로 밀면 완료.
바로 할 수 있는 일은 우선순위·마감 순으로 정렬됩니다.

■ 마감은 캘린더로
월간 캘린더에서 마감일을 한눈에 보고, 길게 눌러 다른 날로 옮길 수 있어요.

■ 어디서나 이어서
폰과 웹(junrepos.github.io/serial-todo)이 실시간으로 동기화되고,
인터넷이 끊겨도 저장했다가 연결되면 자동으로 올립니다.
홈 화면 위젯으로 오늘 할 일을 바로 확인하고 체크하세요.

광고 없음 · 다크 모드 지원
```

**그래픽**: 위 표의 아이콘, 그래픽 이미지, 휴대전화 스크린샷 5장을 올립니다.

**분류**: 앱 카테고리 `생산성`, 태그는 할 일 관리·생산성 중에서 고릅니다.

**연락처 세부정보**: 이메일(필수, 스토어에 공개), 웹사이트 `https://junrepos.github.io/serial-todo/`

### 데이터 보안 (Data safety)

| 질문 | 답변 |
|---|---|
| 필요한 사용자 데이터를 수집하거나 공유하나요? | 예 (수집함) |
| 전송 중 데이터 암호화 | 예 (HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 예 (앱 안 계정 삭제 + 계정 삭제 안내 페이지) |
| 계정 삭제 URL | `https://junrepos.github.io/serial-todo/delete-account.html` |
| 제3자와 공유 | 없음 (Supabase는 처리 위탁이라 "공유"가 아님) |

수집 데이터 유형:

| 유형 | 항목 | 수집 | 필수 여부 | 목적 |
|---|---|---|---|---|
| 개인 정보 | 이메일 주소 | 예 | 필수 | 계정 관리 |
| 앱 활동 | 기타 사용자 생성 콘텐츠(할 일) | 예 | 필수 | 앱 기능 |

위치, 연락처, 사진, 기기 ID, 앱 사용 기록·분석, 금융 정보는 수집하지 않습니다.

## 5. 테스트와 출시

2023년 11월 이후 만든 **개인** 개발자 계정은 바로 프로덕션 출시가 안 됩니다.

1. **비공개 테스트** 트랙 만들기 → 테스터 이메일 목록에 **12명 이상** 추가
2. 최신 Release의 `serial-todo.aab` 업로드 → 출시 노트(예: "첫 출시") → 검토 후 출시
3. 테스터에게 참여 링크를 보내 앱을 설치하게 하고, **14일 연속** 12명 이상이 참여한 상태를 유지
4. 14일이 지나면 대시보드에서 **프로덕션 액세스 신청** → 승인되면 프로덕션 트랙에 같은 AAB로 출시

첫 업로드 때 **Play 앱 서명**을 사용하도록 안내가 나오면 그대로 동의합니다. GitHub Actions가 쓰는 `release.jks`가 업로드 키가 되고, 실제 앱 서명 키는 Google이 보관합니다.

## 참고

- Play에서 받은 앱과 GitHub Release의 APK는 서명이 달라 서로 덮어 설치되지 않습니다. Play 버전으로 옮길 때는 기존 앱을 지우고 설치하세요. 할 일은 서버에 있어 로그인하면 그대로 돌아옵니다.
- 새 버전은 `main`에 push하면 Actions가 버전 코드를 올려 AAB를 만들어 줍니다. 그 AAB를 Console의 해당 트랙에 올리면 됩니다.
- 앱 ID: `io.github.junrepos.serial_todo` (출시 후에는 바꿀 수 없음)
