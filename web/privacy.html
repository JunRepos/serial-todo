할일이많아 개인정보처리방침

시행일: 2026년 11월 10일

할일이많아(이하 "앱")는 할 일을 기기 사이에 동기화하는 데 필요한 최소한의 정보만 처리합니다. 광고나 분석 도구를 쓰지 않으며, 정보를 판매하거나 제3자와 공유하지 않습니다.

1. 처리하는 정보

항목목적보관
이메일 주소, 비밀번호(암호화 저장)로그인과 계정 구분계정 삭제 시까지
사용자가 입력한 할 일(제목, 메모, 마감일, 상태, 선행 관계 등)앱 기능 제공, 기기 간 동기화계정 삭제 시까지
접속 기록(서버 요청 로그)장애 대응·보안서비스 제공자 정책에 따라 단기 보관 후 삭제

위치, 연락처, 사진, 기기 식별자는 수집하지 않습니다.

2. 저장 위치와 처리 위탁

데이터는 Supabase Inc.가 운영하는 서버(서울 리전, ap-northeast-2)에 저장됩니다. 전송 구간은 HTTPS로 암호화되며, 각 사용자는 행 단위 보안 정책(RLS)으로 본인 데이터에만 접근할 수 있습니다. 앱은 오프라인 사용을 위해 할 일 사본을 기기 안에도 저장합니다.

3. 계정과 데이터 삭제

앱의 오른쪽 위 메뉴(⋮) → 계정 삭제를 누르면 계정과 모든 할 일이 서버에서 즉시 영구 삭제됩니다. 앱을 쓸 수 없는 경우 계정 삭제 요청 안내를 참고하세요.

4. 이용자의 권리

이용자는 언제든 자신의 정보를 조회·수정·삭제할 수 있습니다. 할 일은 앱에서 직접 수정·삭제할 수 있고, 계정은 위 방법으로 삭제할 수 있습니다.

5. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않습니다.

6. 문의

개인정보 관련 문의는 GitHub 이슈로 남겨 주세요.

7. 변경

이 방침이 바뀌면 이 페이지에 시행일과 함께 게시합니다.
