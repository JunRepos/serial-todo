할일이많아 계정 삭제

앱에서 바로 삭제 (권장)

  1. 할일이많아 앱 또는 웹에 로그인합니다.
  2. 오른쪽 위 메뉴(⋮) → 계정 삭제를 누릅니다.
  3. 확인 창에서 삭제를 누르면 계정과 모든 할 일이 즉시 영구 삭제됩니다.

앱을 쓸 수 없는 경우

GitHub 이슈로 삭제를 요청해 주세요. 공개 게시판이므로 이메일 주소는 적지 마시고, 요청이 확인되면 본인 확인 방법을 안내해 드립니다. 확인 후 7일 안에 삭제합니다.

삭제되는 정보

이메일·비밀번호 등 계정 정보와 저장한 모든 할 일이 지워지며 복구할 수 없습니다. 서버 접속 기록은 서비스 제공자 정책에 따라 단기간 보관 후 자동 삭제됩니다.
